# Release notes — v1.1.0

**Status:** UI polish, analytics, onboarding/ingest workflows, test harness

---

## Included in v1.1

- **Analytics:** 30-day search volume line chart, top/zero-result bar charts, CSV governance export
- **New hire guide:** bulk Confluence sync from workbook URLs, link-health check
- **Ingest hub:** stable widget keys across tabs, shared background job panel
- **Sidebar:** drag resize with minimum width (full nav labels, no broken wrap)
- **API:** `GET /onboarding/link-health`, `POST /onboarding/sync-confluence`, `search_volume_by_day` on analytics summary
- **Engineering:** `pytest` smoke tests, GitHub Actions CI, Python 3.11 target (`.python-version`)

---

## Still not included (unchanged from v1.0)

- Production SSO, multi-tenant
- Semantic search / cloud LLMs
- Optional local LLM (see [V2_LOCAL_AI_DESIGN.md](V2_LOCAL_AI_DESIGN.md))
